# dbeme 1.0.0 — 2026-10-01

Previous: none · Bump: first release — `main` as first published
(`03e9e19`, 2026-09-27, unversioned) plus the work completed through
2026-10-01: task 18 (edge coupler), the overlap-gauge and interface
corrections it uncovered, and the release commit.

The first public release of the port and extension of
[thdwotjd/dataset-based-eme](https://github.com/thdwotjd/dataset-based-eme)
(Song & Sohn, *Opt. Express* 33, 46815 (2025)). What differs from upstream
is itemised in README → *What changed relative to upstream*; this file
records what 1.0.0 *is*, so that later versions can state what moved.

## Contents

| layer | in 1.0.0 |
|---|---|
| mode solvers | `EmepyFDE` (lossless FD), `PMLBackend` (complex-stretched PML, complex `n_eff`, PML depth per edge), `TargetRulePMLBackend` (shift-invert target chosen per point), `FemwellBackend` (FEM, optional `[fem]` extra, GPL-3.0) — chosen per dataset |
| cross sections | `FullEtchStrip`, `CoupledStrips`, `BiLevelStrip`, `BiLevelPair` (two arms at two heights merging at `gap = 0`), plasmonic slot converters |
| datasets | cached `n_eff`, `TE_pol`, neighbour-only overlaps; identity guard; path-linked updater (one solve per distinct path point) |
| geometry | tapers, Bézier / Euler bends, S-bends, parametric paths; Hungarian mode tracking; one overlap sign per mode in both overlap sets |
| cascade | transfer and scattering-matrix routes, interface projection, reciprocal interface matrix, Redheffer products |
| sources | Gaussian fibre launch projected on the unconjugated biorthogonal basis (`dbeme/propagator/fiber.py`) |
| materials | PyOptik (refractiveindex.info), Sellmeier fallbacks, tabulated data |
| circuit | sax models, phase fits, analytic rings, roughness (Payne–Lacey), circulax extension |
| inverse design | JAX cascade, exactly differentiable in section lengths |
| references | Airy bent slab, 1-D FD PML, SPP / MIM, closed-form rings |
| package | `pip install dbeme[fem,circuit,gds,test]`, MIT, `CITATION.cff` |

## Changes since the unversioned first push (`03e9e19`)

Anyone who cloned `main` between 2026-09-27 and this release has a
different solver. Details, magnitudes and evidence are in README → *What
changed relative to upstream*, under the headings named here.

* **Results changed.** *One sign per mode in both overlap sets* — the sign
  equalisation was derived independently for `overlap_ab` and `overlap_ba`;
  on a PML basis this moved coupling between `T` and `R`. Report 22's
  band-edge TE loss and report 13 §12's 312-section cascade change; lossless
  datasets and the warm paths of reports 12 and 13 on their headline
  datasets are bit-identical. *Interface reflection block* corrected.
* **Default changed.** `SingleEME.INTERFACE_COLUMN_CAP` is now `False`
  (opt-in with `"auto"` / `True`); report 13's capped numbers say so.
* **Added.** `SingleEME.INTERFACE_RECIPROCAL`, `INTERFACE_SELF_OVERLAP`;
  `BiLevelPair`; `TargetRulePMLBackend`; per-edge PML depth; the fibre
  launch; a minimum-degree ordering for the shift-invert factorisation
  (`eigs` 102 → 63 s on 146 k unknowns, eigenvalues unchanged to 1e-13).
* **Datasets.** `BASIS_CONVENTION` stays 2; caches built at `03e9e19` are
  expected to load (confirm with one warm run before tagging).

## Compatibility keys

Datasets and path caches built by 1.0.0 carry these; a later version that
changes one of them must say so under *Datasets invalidated* or *Results
changed*.

|---|---|
| `dataset_identity.BASIS_CONVENTION` | `2` (Löwdin biorthogonalisation in the unconjugated metric) |

## Validated baseline

The numbers later *Results changed* entries are measured against; sources
as in README → *Validation at a glance*.

| check | 1.0.0 |
|---|---|
| constant-width guide | T = 1.0000 ± 2e-4 |
| reciprocity, lossless basis | `T_fwd = T_bwdᵀ` to 2e-5; reflection blocks symmetric to 1e-12 |
| reciprocity, lossy truncated basis | 1e-3 on the launched channel |
| PML vs exact Airy bent slab | worst 2.03 % over 5.6 decades of `Im n_eff` |
| bend loss vs Vlasov & McNab 2004 | within 19 % at R = 1 µm |
| backend vs emepy rectangle solver | 1e-3 |
| dataset vs direct EME | ~2e-5 on tapers; warm sweep 460× faster |
| Kocabaş converter vs paper | 87.0 % modal, column cap opted in (report 13 §12); 89–91 % on the paper's measure (paper ~95 %) |
| edge coupler vs Wan & Wang 2025 3D-FDTD | TE within 0.1 dB; TM 0.5–0.6 dB high (report 22; its PDL gate fails) |

## Examples, reports, datasets

* Reports 01–06, 12, 13, 16, 16_1, 22 (adiabatic coupler, polarization
  rotator, O-band sweep, sidewall angle, RAC, PML gate, plasmonic and
  Kocabaş converters, ring resonator, MRM, O-band double-tip edge coupler).

* **Release assets, not in git:** `Si_bilevel_pair_220_150nm_ox_{1260,1310,1360}`
  (overlap pickles 60–113 MB; GitHub rejects files over 100 MB). Their
  `dataset_info.py` and `fingerprint.json` are in git; the zips attached to
  this release unpack into `datasets/`.
* 38 test files under `tests/`, one under `tests_circuit/`.

## Known limitations

As stated in README → *What it is not* and `docs/accuracy_and_limitations.md`:
one wavelength per dataset; no loss on the default backend; convergence at
metal corners, anti-crossings and staircase floors is per device. Report
22's TM result fails its PDL gate.
